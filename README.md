# Abhishek — SMS Spam Detection Using Machine Learning

## Overview
Classifies SMS text as spam or ham using TF-IDF features and compares Multinomial Naive Bayes with Logistic Regression.

## Tools
Python, pandas, Matplotlib, scikit-learn, TF-IDF.

## Dataset
The notebook downloads the public UCI SMS Spam Collection dataset on first run. Internet access is needed for the download.

## Run
1. Install Python 3.10+.
2. Run `pip install -r requirements.txt`.
3. Open `Abhishek_SMS_Spam_Detection.ipynb` in Jupyter or Google Colab.
4. Run cells from top to bottom.

## Evaluation
The notebook computes accuracy, precision, recall, F1-score and a confusion matrix. Actual scores are generated at run time; do not invent or assume results.

Educational project only. Predictions are not guaranteed to be correct.
